Rules applied by this converter
Sheet & header handling — only the SKU tab is read (PREPACK and any other tabs are ignored). The converter finds the DEPARTMENT header row wherever it sits, so titles above it like PO - Barcode -SKU are skipped, and bottom totals rows (blank lines with only an ORDER_QTY sum) are dropped.
DEPARTMENT — only the first space becomes a hyphen; text stays UPPERCASE. ACC BAGS → ACC-BAGS, KW 2-8 YRS GIRLS → KW-2-8 YRS GIRLS
MRP — values of 1000+ get a space as thousands separator. 1499 → 1 499; 799 stays 799
MONTH_YEAR — every value normalised to MM/YYYY text. 01-Aug-26 (date cell) → 08/2026
PRODUCT — Title Case each word. SWEATSHIRT AND PANT → Sweatshirt And Pant
SIZE_DESC — Title Case, but units CM/M go fully lowercase and the separator X stays uppercase. CHEST-62 CM WAIST-44 CM → Chest-62 cm Waist-44 cm
QTY — Title Case the unit word. 1 NUMBER → 1 Number, 1 SET → 1 Set
ITEM_CODE, EAN_BARCODE, PO_NUMBER — always written as plain text with every digit shown, never scientific notation. 1.00002E+12 → 1000016816762
Master file — "Download all as ZIP" also includes MASTER_Buyer_File_<date>.xlsx, which stacks the converted rows from every uploaded file (in upload order) into one sheet with the standard column layout. "Download master only" saves just that file.
All other columns (CLASS - SUBCLASS, SEASON_SUPPLIER_CODE, STYLE_CODE_GROUP, CODE, COLOUR, ORDER_QTY) are copied through unchanged. Note columns after PO_NUMBER (e.g. "CLIENT FILE") are dropped.
